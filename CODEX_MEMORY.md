# Project Memory

This repository is the mobile app for **Medmacs.app**, Pakistan's best MBBS learning platform.

Related Medmacs repositories:

- `Medistics-seniors`: web app and selected APIs
- `medmacs-ai`: AI-related APIs
- `medmacs-supers`: admin panel

The separate **Medistics.app** ecosystem (Pakistan's best MDCAT learning platform) consists of `fetch-friend` (mobile), `medistics-pakistan` (web and APIs), and `mcatpanel` (admin).
